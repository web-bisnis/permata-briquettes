# Content Collections

Konten publik berasal dari dokumen kanonis `website_copy_permata_briquettes.md` dan divalidasi oleh `src/content.config.ts`.

- `pages/` berisi copy halaman bilingual dalam Markdown beserta metadata route dan keputusan internal nonpublik.
- `products/` berisi data produk terstruktur dalam YAML, termasuk grade, spesifikasi referensi, ukuran, kemasan, dan keputusan internal nonpublik.
- `decisions/` berisi register typed untuk konten tertahan, ambigu, atau masih menunggu persetujuan; koleksi ini tidak dirender.

Catatan internal tidak dirender oleh route publik. Dokumen legal asli, kanal kontak, dan nilai yang belum terverifikasi tidak disimpan di direktori ini.
